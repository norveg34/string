SLK2 String PWA – Android

A saját SLK2_String.xlsx fájlt cseréld le a csomagban lévő minta Excelre. A fájl első munkalapján a fejlécnek tartalmaznia kell: ROW, STRING, TERULET.

Telepítés:
1. Töltsd fel a mappát HTTPS webtárhelyre.
2. Android Chrome-ban nyisd meg.
3. Chrome menü -> Alkalmazás telepítése / Hozzáadás a kezdőképernyőhöz.
4. Első online indításkor az Excel helyi adatbázisba kerül.
5. Ezután internet nélkül is kereshető.
6. Online indításkor frissítést ellenőriz; futó alkalmazásnál óránként is ellenőriz.

Megjegyzés: teljesen bezárt háttérben lévő Android PWA esetén az óránkénti háttérfrissítés nem garantálható; a következő megnyitáskor biztosan ellenőriz.
